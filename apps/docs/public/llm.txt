# SSGOI - Page Transition Library for AI Assistants

> Universal page transition library for web applications. Works in all modern browsers (Chrome, Firefox, Safari), unlike browser's View Transition API (Chrome-only).

This document is optimized for LLM/AI assistants to help developers implement SSGOI page transitions.

## Quick Reference

### Minimal Next.js Setup (Copy-Paste Ready)

```tsx
// 1. app/layout.tsx
import { Ssgoi } from "@ssgoi/react";
import { fade } from "@ssgoi/react/view-transitions";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <body>
        <Ssgoi config={{ defaultTransition: fade() }}>
          {/* CRITICAL: This wrapper div is REQUIRED */}
          <div style={{ position: "relative", zIndex: 0, minHeight: "100vh" }}>
            {children}
          </div>
        </Ssgoi>
      </body>
    </html>
  );
}

// 2. app/page.tsx
import { SsgoiTransition } from "@ssgoi/react";

export default function HomePage() {
  return (
    <SsgoiTransition id="/">
      <main>Your content here</main>
    </SsgoiTransition>
  );
}
```

## Core Concepts & Architecture

### How SSGOI Page Transitions Work

SSGOI creates smooth page transitions by orchestrating the exit animation of the leaving page and the enter animation of the arriving page simultaneously.

```
Route Change Flow:
1. User navigates from /home to /about
2. SSGOI receives "OUT" signal from /home page (leaving)
3. SSGOI receives "IN" signal from /about page (entering)
4. SSGOI finds matching transition config for /home -> /about
5. Both pages animate simultaneously:
   - /home: OUT animation (e.g., fade out, slide left)
   - /about: IN animation (e.g., fade in, slide from right)
6. When animations complete, cleanup occurs
```

### Why `position: relative` is REQUIRED on the Container

**This is the most common issue when setting up SSGOI.**

During the OUT animation, the leaving page's styles are modified:

```typescript
// Internal: packages/core/src/lib/utils/prepare-outgoing.ts
export const prepareOutgoing = (element: HTMLElement, context?: SggoiTransitionContext) => {
  element.style.position = "absolute";  // CRITICAL: Page becomes absolute
  element.style.width = "100%";
  element.style.top = `${-1 * (context?.scrollOffset?.y ?? 0)}px`;
  element.style.left = "0";
};
```

**What happens without `position: relative`:**
- The leaving page (now `position: absolute`) will position itself relative to the nearest positioned ancestor
- If no positioned ancestor exists, it positions relative to the document body
- This causes the page to "jump" to an incorrect position during the animation

**What `position: relative` does:**
- Creates a positioning context for the absolute-positioned leaving page
- The leaving page stays in place visually while animating out
- The entering page can slide/fade into the same space

### Why `z-index: 0` is Recommended

Adding `z-index: 0` creates a new **stacking context**:

```css
/* Without z-index: 0 */
.container { position: relative; }
/* Child elements with z-index may escape and overlap incorrectly */

/* With z-index: 0 */
.container { position: relative; z-index: 0; }
/* Creates isolated stacking context - child z-indexes stay contained */
```

**Benefits:**
- Prevents z-index conflicts during transitions
- Child elements with high z-index won't escape the container
- Ensures consistent layering between leaving and entering pages

### The Ssgoi Component Architecture

```
<Ssgoi config={...}>
  ├── Creates transition context
  ├── Manages pending transitions (waiting for both OUT and IN)
  ├── Handles route matching
  └── <div style={{ position: "relative", zIndex: 0 }}>
        ├── <SsgoiTransition id="/home">  (Page A - will animate OUT)
        └── <SsgoiTransition id="/about"> (Page B - will animate IN)
      </div>
</Ssgoi>
```

## Next.js Complete Setup Guide

### Step 1: Install the Package

```bash
npm install @ssgoi/react
```

### Step 2: Configure Root Layout

```tsx
// app/layout.tsx
import { Ssgoi } from "@ssgoi/react";
import { fade, scroll, drill, hero } from "@ssgoi/react/view-transitions";
import type { ReactNode } from "react";

// Define your transition configuration
const config = {
  // Default transition for routes without specific config
  defaultTransition: fade(),

  // Route-specific transitions
  transitions: [
    // Scroll between main pages
    { from: "/", to: "/about", transition: scroll({ direction: "up" }) },
    { from: "/about", to: "/", transition: scroll({ direction: "down" }) },

    // Drill into detail pages (wildcard pattern)
    { from: "/products", to: "/products/*", transition: drill({ direction: "enter" }) },
    { from: "/products/*", to: "/products", transition: drill({ direction: "exit" }) },

    // Hero transition for galleries
    { from: "/gallery", to: "/gallery/*", transition: hero(), symmetric: true },

    // Symmetric: automatically creates reverse transition
    { from: "/blog", to: "/blog/*", transition: fade(), symmetric: true },
  ],
};

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en">
      <body>
        <Ssgoi config={config}>
          {/*
            CRITICAL: This wrapper is REQUIRED for transitions to work
            - position: relative - Creates positioning context for absolute pages
            - zIndex: 0 - Creates stacking context for proper layering
            - minHeight: 100vh - Ensures container fills viewport
          */}
          <div style={{ position: "relative", zIndex: 0, minHeight: "100vh" }}>
            {children}
          </div>
        </Ssgoi>
      </body>
    </html>
  );
}
```

### Step 3: Wrap Each Page with SsgoiTransition

Every page that participates in transitions must be wrapped:

```tsx
// app/page.tsx (Home page)
import { SsgoiTransition } from "@ssgoi/react";

export default function HomePage() {
  return (
    <SsgoiTransition id="/">
      <main className="min-h-screen p-8">
        <h1>Home Page</h1>
        {/* Page content */}
      </main>
    </SsgoiTransition>
  );
}
```

```tsx
// app/about/page.tsx
import { SsgoiTransition } from "@ssgoi/react";

export default function AboutPage() {
  return (
    <SsgoiTransition id="/about">
      <main className="min-h-screen p-8">
        <h1>About Page</h1>
        {/* Page content */}
      </main>
    </SsgoiTransition>
  );
}
```

```tsx
// app/products/page.tsx
import { SsgoiTransition } from "@ssgoi/react";

export default function ProductsPage() {
  return (
    <SsgoiTransition id="/products">
      <main className="min-h-screen p-8">
        <h1>Products</h1>
        {/* Product list */}
      </main>
    </SsgoiTransition>
  );
}
```

```tsx
// app/products/[id]/page.tsx
import { SsgoiTransition } from "@ssgoi/react";

export default function ProductDetailPage({ params }: { params: { id: string } }) {
  return (
    <SsgoiTransition id={`/products/${params.id}`}>
      <main className="min-h-screen p-8">
        <h1>Product {params.id}</h1>
        {/* Product details */}
      </main>
    </SsgoiTransition>
  );
}
```

### Step 4: (Optional) Setup Auto Key Plugin for Element Transitions

The Auto Key Plugin automatically generates unique keys for `transition()` calls:

```typescript
// next.config.ts
import type { NextConfig } from "next";
import SsgoiAutoKey from "@ssgoi/react/unplugin/webpack";

const nextConfig: NextConfig = {
  webpack: (config) => {
    config.plugins.push(SsgoiAutoKey());
    return config;
  },
};

export default nextConfig;
```

**With plugin:** Keys are auto-generated based on file:line:column
```tsx
<div ref={transition(fade())}>Content</div>
```

**Without plugin:** Keys must be manually specified
```tsx
<div ref={transition({ key: "my-element", ...fade() })}>Content</div>
```

## View Transitions (Page-level)

View transitions animate between pages. Import from `@ssgoi/react/view-transitions`.

### Available Transitions

| Transition | Description | Best For |
|------------|-------------|----------|
| `fade()` | Smooth opacity transition | General purpose, sibling content |
| `scroll()` | Vertical scrolling | Sequential pages, timelines |
| `drill()` | iOS-style drill in/out | Hierarchical navigation |
| `hero()` | Shared element animation | Same object, different views |
| `pinterest()` | Card expansion effect | Image galleries |
| `slide()` | Horizontal sliding | Tab-like navigation |
| `sheet()` | Bottom sheet style | Modal-like content |
| `instagram()` | Instagram-style transition | Social media galleries |
| `depth()` | Depth-based transition | Layered navigation |
| `snap()` | Snap-scroll effect | Carousel-like navigation |
| `blind()` | Venetian blind effect | Creative transitions |
| `film()` | Film reel effect | Portfolio, showcases |

### Transition Configuration

```typescript
interface SsgoiConfig {
  transitions?: Array<{
    from: string;      // Source route pattern
    to: string;        // Destination route pattern
    transition: ViewTransition;
    symmetric?: boolean; // Auto-create reverse transition
  }>;
  defaultTransition?: ViewTransition;
}
```

### Route Pattern Matching

```typescript
// Exact match
{ from: "/home", to: "/about" }  // Only /home -> /about

// Wildcard suffix
{ from: "/products", to: "/products/*" }  // /products -> /products/123

// Full wildcard
{ from: "*", to: "*" }  // Any route to any route (use as default)
```

**Priority:** Exact match > Wildcard match > defaultTransition

### Examples by Use Case

```typescript
import { fade, scroll, drill, hero, pinterest } from "@ssgoi/react/view-transitions";

const config = {
  transitions: [
    // === Vertical navigation (scroll) ===
    { from: "/home", to: "/features", transition: scroll({ direction: "up" }) },
    { from: "/features", to: "/pricing", transition: scroll({ direction: "up" }) },
    { from: "/pricing", to: "/features", transition: scroll({ direction: "down" }) },
    { from: "/features", to: "/home", transition: scroll({ direction: "down" }) },

    // === Hierarchical navigation (drill) ===
    {
      from: "/settings",
      to: "/settings/*",
      transition: drill({ direction: "enter" }),
      symmetric: false  // Define exit explicitly
    },
    {
      from: "/settings/*",
      to: "/settings",
      transition: drill({ direction: "exit" })
    },

    // === Shared element (hero) ===
    // Requires data-hero-key attribute on matching elements
    { from: "/team", to: "/team/*", transition: hero(), symmetric: true },

    // === Image gallery (pinterest) ===
    // Requires data-pinterest-gallery-key and data-pinterest-detail-key
    { from: "/gallery", to: "/gallery/*", transition: pinterest(), symmetric: true },

    // === Simple bidirectional (symmetric) ===
    { from: "/login", to: "/signup", transition: fade(), symmetric: true },
  ],
  defaultTransition: fade(),
};
```

### Hero Transition Setup

Hero transitions require matching `data-hero-key` attributes:

```tsx
// List page
function ProductList() {
  return (
    <div className="grid">
      {products.map(product => (
        <Link key={product.id} href={`/product/${product.id}`}>
          <img
            data-hero-key={`product-${product.id}`}  // REQUIRED
            src={product.image}
            alt={product.name}
          />
        </Link>
      ))}
    </div>
  );
}

// Detail page
function ProductDetail({ product }) {
  return (
    <div>
      <img
        data-hero-key={`product-${product.id}`}  // MUST MATCH
        src={product.image}
        alt={product.name}
      />
    </div>
  );
}
```

### Pinterest Transition Setup

Pinterest transitions require different attributes for gallery and detail:

```tsx
// Gallery page
<div data-pinterest-gallery-key={item.id}>
  <img src={item.thumbnail} />
</div>

// Detail page
<div data-pinterest-detail-key={item.id}>
  <img src={item.fullImage} />
</div>
```

## Element Transitions (Component-level)

Animate individual elements on mount/unmount. Import from `@ssgoi/react/transitions`.

### Available Presets

```typescript
import {
  fade,    // Opacity transition
  scale,   // Scale in/out
  slide,   // Slide from direction
  fly,     // Custom x/y position
  blur,    // Blur effect
  rotate,  // Rotation
  bounce,  // Bounce effect
} from "@ssgoi/react/transitions";
```

### Usage with transition() Function

```tsx
import { transition } from "@ssgoi/react";
import { fade, scale, slide } from "@ssgoi/react/transitions";

function MyComponent({ show }) {
  return show && (
    <>
      {/* Basic usage (with Auto Key Plugin) */}
      <div ref={transition(fade())}>Fade effect</div>

      {/* With options */}
      <div ref={transition(scale({
        start: 0.8,
        physics: { spring: { stiffness: 300, damping: 30 } }
      }))}>
        Scale effect
      </div>

      {/* Slide with direction */}
      <div ref={transition(slide({ direction: "left" }))}>
        Slide from left
      </div>

      {/* Without plugin - explicit key required */}
      <div ref={transition({ key: "my-element", ...fade() })}>
        Explicit key
      </div>
    </>
  );
}
```

### In Lists (.map)

```tsx
// With Auto Key Plugin: JSX key is enough
function ItemList({ items }) {
  return items.map(item => (
    <div
      key={item.id}  // JSX key - plugin auto-generates transition key
      ref={transition(fade())}
    >
      {item.name}
    </div>
  ));
}

// Without plugin: explicit transition key required
function ItemListManual({ items }) {
  return items.map(item => (
    <div
      key={item.id}
      ref={transition({ key: `item-${item.id}`, ...fade() })}
    >
      {item.name}
    </div>
  ));
}
```

### Custom Transitions

```tsx
// Using css (recommended - Web Animation API)
<div ref={transition({
  key: "custom-css",
  in: () => ({
    physics: { spring: { stiffness: 300, damping: 30 } },
    css: (progress) => ({
      opacity: progress,
      transform: `translateY(${(1 - progress) * 20}px)`,
    }),
  }),
  out: () => ({
    physics: { spring: { stiffness: 300, damping: 30 } },
    css: (progress) => ({
      opacity: progress,
      transform: `translateY(${(1 - progress) * 20}px)`,
    }),
  }),
})}>
  CSS-based animation
</div>

// Using tick (RAF-based - for complex DOM manipulation)
<div ref={transition({
  key: "custom-tick",
  in: (element) => ({
    physics: { spring: { stiffness: 300, damping: 30 } },
    tick: (progress) => {
      element.style.opacity = String(progress);
      element.style.transform = `scale(${0.8 + progress * 0.2})`;
    },
  }),
})}>
  Tick-based animation
</div>
```

### TransitionScope

Control animation behavior for grouped elements:

```tsx
import { TransitionScope, transition } from "@ssgoi/react";
import { fade } from "@ssgoi/react/transitions";

function Modal({ show }) {
  return show && (
    <TransitionScope>
      <div className="modal">
        {/* scope: 'local' - skips animation when parent mounts/unmounts */}
        <div ref={transition({ ...fade(), scope: "local" })}>
          Won't animate when modal opens/closes
        </div>

        {/* scope: 'global' (default) - always animates */}
        <div ref={transition({ ...fade() })}>
          Always animates
        </div>
      </div>
    </TransitionScope>
  );
}
```

## Physics & Animation Options

### Spring Physics (Default - Ease-Out)

```typescript
fade({
  physics: {
    spring: {
      stiffness: 300,  // Higher = faster animation
      damping: 30,     // Higher = less bouncy
    }
  }
})
```

### Double Spring (Ease-In-Out)

```typescript
fade({
  physics: {
    spring: {
      stiffness: 300,
      damping: 30,
      doubleSpring: true  // Creates ease-in-out effect
    }
  }
})
```

### Inertia Physics (Ease-In)

```typescript
drill({
  direction: "enter",
  physics: {
    inertia: {
      acceleration: 20,   // Higher = faster acceleration
      resistance: 1.5,    // Higher = more deceleration
      resistanceType: "quadratic"  // 'linear' | 'quadratic'
    }
  }
})
```

### Spring Presets

```typescript
import { config } from "@ssgoi/react/presets";

// Available presets
config.default   // { stiffness: 170, damping: 26 } - General purpose
config.gentle    // { stiffness: 120, damping: 14 } - Smooth, elegant
config.wobbly    // { stiffness: 180, damping: 12 } - Bouncy, playful
config.stiff     // { stiffness: 210, damping: 20 } - Quick, responsive
config.slow      // { stiffness: 280, damping: 60 } - Deliberate
config.molasses  // { stiffness: 150, damping: 60 } - Very slow

// Usage
fade({ physics: { spring: config.gentle } })
```

## Common Pitfalls & Troubleshooting

### Issue: Page "jumps" during transition

**Cause:** Missing `position: relative` on container

**Fix:**
```tsx
<Ssgoi config={config}>
  <div style={{ position: "relative", zIndex: 0, minHeight: "100vh" }}>
    {children}
  </div>
</Ssgoi>
```

### Issue: Transitions not working at all

**Cause:** Missing `SsgoiTransition` wrapper on pages

**Fix:** Every page must be wrapped:
```tsx
<SsgoiTransition id="/your-route">
  {/* page content */}
</SsgoiTransition>
```

### Issue: Wrong transition applied

**Cause:** `id` prop doesn't match route pattern

**Fix:** Ensure `id` matches the actual route path:
```tsx
// For /products/123
<SsgoiTransition id={`/products/${params.id}`}>
```

### Issue: Z-index conflicts during transition

**Cause:** Missing stacking context

**Fix:** Add `zIndex: 0` to create stacking context:
```tsx
<div style={{ position: "relative", zIndex: 0 }}>
```

### Issue: Hero/Pinterest not animating

**Cause:** Missing or mismatched data attributes

**Fix:**
```tsx
// Hero: same data-hero-key on both pages
<img data-hero-key={`item-${id}`} />

// Pinterest: different attributes for gallery vs detail
<div data-pinterest-gallery-key={id}>  // Gallery
<div data-pinterest-detail-key={id}>   // Detail
```

### Issue: Element transitions not preserving state

**Cause:** Missing or non-unique keys

**Fix:** Use Auto Key Plugin or provide unique keys:
```tsx
ref={transition({ key: "unique-key", ...fade() })}
```

## API Reference

### Ssgoi Component

```typescript
interface SsgoiProps {
  config: SsgoiConfig;
  children: ReactNode;
}

interface SsgoiConfig {
  transitions?: TransitionRule[];
  defaultTransition?: ViewTransition;
  middleware?: (from: string, to: string) => { from: string; to: string };
  skipOnIosSwipe?: boolean;  // Default: true
}

interface TransitionRule {
  from: string;
  to: string;
  transition: ViewTransition;
  symmetric?: boolean;
}
```

### SsgoiTransition Component

```typescript
interface SsgoiTransitionProps {
  id: string;          // Route identifier (must match route pattern)
  children: ReactNode;
  as?: ElementType;    // Default: "div"
  className?: string;
}
```

### transition() Function

```typescript
function transition(config: TransitionConfig | Preset): RefCallback<HTMLElement>;

interface TransitionConfig {
  key?: string;  // Required if not using Auto Key Plugin
  in?: (element: HTMLElement) => TransitionDefinition;
  out?: (element: HTMLElement) => TransitionDefinition;
  scope?: "global" | "local";  // Default: "global"
}

interface TransitionDefinition {
  physics?: PhysicsOptions;
  css?: (progress: number) => CSSProperties;  // OR
  tick?: (progress: number) => void;          // Cannot use both
  prepare?: (element: HTMLElement) => void;
  onStart?: () => void;
  onEnd?: () => void;
}
```

### View Transition Options

```typescript
// fade()
interface FadeOptions {
  physics?: PhysicsOptions;
  inPhysics?: PhysicsOptions;
  outPhysics?: PhysicsOptions;
}

// scroll()
interface ScrollOptions {
  direction?: "up" | "down";
  physics?: PhysicsOptions;
}

// drill()
interface DrillOptions {
  direction?: "enter" | "exit";
  opacity?: boolean;
  physics?: { inertia?: InertiaConfig };
}

// hero() - no options, uses data-hero-key attributes

// pinterest() - no options, uses data-pinterest-*-key attributes
```

## For AI Assistants

When helping users implement SSGOI:

1. **Always include the wrapper div** with `position: relative` and `zIndex: 0`
2. **Ensure every page has SsgoiTransition** with correct `id` matching the route
3. **For dynamic routes**, use template literals: `id={\`/products/\${id}\`}`
4. **Recommend Auto Key Plugin** for Next.js to simplify element transitions
5. **Check data attributes** for hero/pinterest transitions
6. **Start with fade()** as default transition, then customize

Example complete setup flow:
1. `npm install @ssgoi/react`
2. Create layout with Ssgoi wrapper and positioned container
3. Wrap each page with SsgoiTransition
4. Configure transitions in layout
5. (Optional) Add Auto Key Plugin for element animations
