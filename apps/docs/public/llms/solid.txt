# SSGOI with SolidStart

Use one config and one `<Ssgoi>` at the router root.

```tsx
// src/app.tsx
import { Router } from "@solidjs/router";
import { FileRoutes } from "@solidjs/start/router";
import { Ssgoi } from "@ssgoi/solid";
import { config } from "./ssgoi-config";

<Router
  root={(props) => (
    <main class="relative z-0 min-h-dvh overflow-x-clip">
      <Ssgoi config={config}>{props.children}</Ssgoi>
    </main>
  )}
>
  <FileRoutes />
</Router>
```

## Page boundary

```tsx
export default function Post() {
  const location = useLocation();

  return (
    <article data-ssgoi-transition={location.pathname}>
      {/* page */}
    </article>
  );
}
```

## Persistent layout

Put an outer boundary on the route layout and keep child page boundaries.

```tsx
export default function ProductsLayout(props) {
  const location = useLocation();

  return (
    <section data-ssgoi-transition={location.pathname}>
      <ProductTabs />
      {props.children}
    </section>
  );
}
```

The child boundary handles tab changes. If the entire layout leaves, SSGOI uses
the outer changed boundary.
