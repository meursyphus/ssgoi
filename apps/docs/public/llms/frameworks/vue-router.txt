# SSGOI with Vue Router

Experimental API: this router integration may change.

Install @ssgoi/vue in an existing Vue Router application.
Return Vue Router 4's current path from `framework.getRoute` on the common Vue provider.

Keep one common provider above the following boundary.

## Wrap the routed region

The boundary follows the committed router path and replaces its DOM root when the route key changes. SsgoiLayoutBoundary throws if <Ssgoi> has no framework.

```vue
<script setup lang="ts">
import { RouterView, useRouter } from "vue-router";
import { Ssgoi, SsgoiLayoutBoundary } from "@ssgoi/vue";
import { config } from "./ssgoi-config";

const router = useRouter();
const framework = {
  getRoute: () => ({ pathname: router.currentRoute.value.path }),
};
</script>

<template>
  <Ssgoi :config="config" :framework="framework">
    <SsgoiLayoutBoundary><RouterView /></SsgoiLayoutBoundary>
  </Ssgoi>
</template>
```

## Persistent shells

Use a fixed key such as boundary="shell" for the outer shell and a changing inner boundary for the page. The function form of boundary receives the route getRoute returned, here { pathname }, as-is and returns a key string or { id?, key? }.

SsgoiRouteBoundary from @ssgoi/vue/vue-router still works but is deprecated and will be removed in 8.0.0.

Common setup: https://ssgoi.dev/llms/frameworks/vue.txt
