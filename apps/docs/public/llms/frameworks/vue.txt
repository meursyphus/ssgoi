# SSGOI with Vue

Use the Vue package for the provider and effects. Choose the helper for the router already installed in your app.

Install @ssgoi/vue. Keep one provider above the changing page region.

## Common setup

Install @ssgoi/vue and keep one Ssgoi provider above RouterView or NuxtPage. It receives the shared route configuration.

```ts
import { Ssgoi } from "@ssgoi/vue";
import { drill } from "@ssgoi/vue/view-transitions";
```

## Transition state

A page that scrolls itself on arrival (anchor jump, scrollIntoView) fights
the animation. Read the provider's transition state and act once it is idle.
The status is `idle` or `transitioning`; while transitioning it also carries
`from`, `to` and `direction`. It flips as soon as the navigation is paired,
one microtask after the DOM changed, and returns to `idle` when the run
releases, the same span the scroll-input lock covers.
`useSsgoiTransition` returns a readonly ref; call it in `setup`.

```vue
<script setup lang="ts">
import { watch } from "vue";
import { useSsgoiTransition } from "@ssgoi/vue";

const transition = useSsgoiTransition();

watch(
  () => transition.value.status,
  (status) => {
    if (status !== "idle") return;
    document.getElementById("comments")?.scrollIntoView();
  },
  { immediate: true },
);
</script>
```
