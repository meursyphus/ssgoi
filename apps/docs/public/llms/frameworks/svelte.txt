# SSGOI with Svelte

The Svelte package provides the common provider and transition API. Add the SvelteKit helper when Kit owns navigation.

Install @ssgoi/svelte. Keep one provider above the changing page region.

## Common setup

Install @ssgoi/svelte and keep one Ssgoi provider above the changing page region. Transition factories and route rules are shared with the other web packages.

```ts
import { Ssgoi } from "@ssgoi/svelte";
import { drill } from "@ssgoi/svelte/view-transitions";
```

## Transition state

A page that scrolls itself on arrival (anchor jump, scrollIntoView) fights
the animation. Read the provider's transition state and act once it is idle.
The status is `idle` or `transitioning`; while transitioning it also carries
`from`, `to` and `direction`. It flips as soon as the navigation is paired,
one microtask after the DOM changed, and returns to `idle` when the run
releases, the same span the scroll-input lock covers.
`getSsgoiTransition` returns a readable store; call it during component
initialisation.

```svelte
<script lang="ts">
  import { getSsgoiTransition } from "@ssgoi/svelte";

  const transition = getSsgoiTransition();

  $effect(() => {
    if ($transition.status !== "idle") return;
    document.getElementById("comments")?.scrollIntoView();
  });
</script>
```
