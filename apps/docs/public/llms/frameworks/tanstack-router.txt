# SSGOI with TanStack Router

TanStack Router wiring. Choose effects from:
https://ssgoi.dev/llms/transitions.txt

```bash
npm install @ssgoi/react
```

Shell class strings below are Tailwind shorthand. Without Tailwind, apply
`position: relative; z-index: 0; min-height: 100dvh; overflow-x: clip`. Use
`clip`, not `hidden`: `overflow-x: hidden` makes the wrapper the scroll
container, and scroll restore then targets the wrong element. Fall back to
`100vh` only where `dvh` is unsupported.

## Setup

Config:

```ts
// app/components/ssgoi-config.ts
import { drill } from "@ssgoi/react/view-transitions";

export const config = {
  transitions: [{ on: "/**", except: "/", transition: drill() }],
};
```

Everything wires in the root route — one `<Ssgoi>`, the shell classes, and
the boundary around `<Outlet />`:

```tsx
// app/routes/__root.tsx
import { createRootRoute, Outlet } from "@tanstack/react-router";
import { Ssgoi } from "@ssgoi/react";
import { config } from "~/components/ssgoi-config";
import { SsgoiRouteBoundary } from "@ssgoi/react/tanstack-router";

export const Route = createRootRoute({
  component: () => (
    <main className="relative z-0 min-h-dvh overflow-x-clip">
      <Ssgoi config={config}>
        <SsgoiRouteBoundary>
          <Outlet />
        </SsgoiRouteBoundary>
      </Ssgoi>
    </main>
  ),
});
```

Boundary — pathname (from router state) as both React key and transition id:

```tsx
import { SsgoiRouteBoundary } from "@ssgoi/react/tanstack-router";
: {
  children: ReactNode;
  name?: BoundaryName;
}) {
  const pathname = useRouterState({
    select: (state) => state.location.pathname,
  });
  const boundary = resolveBoundary(name, pathname);

  return (
    <div key={boundary.key} data-ssgoi-transition={boundary.id}>
      {children}
    </div>
  );
}
```

Verify: navigate `/` → any page slides in from the right; back slides out.

## Beyond the basics

When a section must persist, remove the full-path boundary from the root and
leave only one provider there:

```tsx
<Ssgoi config={config}>
  <Outlet />
</Ssgoi>
```

Give ordinary routes their own pathname boundary. Give the persistent section
a stable outer boundary plus a pathname boundary around its child outlet:

```tsx
// app/routes/products.tsx
<SsgoiRouteBoundary routeKey="products-layout">
  <ProductHeaderAndTabs />
  <SsgoiRouteBoundary>
    <Outlet />
  </SsgoiRouteBoundary>
</SsgoiRouteBoundary>
```

The outer `routeKey` is stable; the inner boundary defaults to the pathname. The stable outer key
preserves the shell; the inner pathname key produces child OUT/IN.

- Key-scope reasoning: https://ssgoi.dev/llms/complex-routing.txt
- Full example: https://github.com/meursyphus/ssgoi/tree/HEAD/templates/tanstack-router
- Framework index: https://ssgoi.dev/llms/frameworks.txt

The `@ssgoi/react/tanstack-router` subpath uses only its optional router peer.
Root imports and other router entries do not load it. `as`, DOM attributes,
`routeKey`, and `resolve` are supported. Resolve returns `{ id, key? }`; key
defaults to id, and routeKey overrides it. Query-only navigation keeps the
boundary by default. For direct control or a custom router:
https://ssgoi.dev/llms/manual-boundaries.txt
