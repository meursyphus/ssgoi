# SSGOI transition catalog

Choose the effect from the interaction the user should understand. Each linked
spec contains its variants, supported props, required markup, and a focused
route-config example.

Main setup: https://ssgoi.dev/llms.txt

## Core UX patterns

| UX intent | transition | platform | usual rule | spec |
| --- | --- | --- | --- | --- |
| list → detail, hierarchical depth | `drill()` | mobile | `on` + `except` | https://ssgoi.dev/llms/transitions/drill.txt |
| compose, filters, temporary task | `sheet()` | mobile + web | `on` | https://ssgoi.dev/llms/transitions/sheet.txt |
| tabs or ordered horizontal steps | `slide()` | mobile | `ordered` | https://ssgoi.dev/llms/transitions/slide.txt |
| sibling pages with Material shared-axis motion | `axis()` | mobile | `ordered` | https://ssgoi.dev/llms/transitions/axis.txt |
| card or image expands into detail | `zoom()` | mobile | `from` / `to` | https://ssgoi.dev/llms/transitions/zoom.txt |
| vertical full-page sequence | `scroll()` | web | `ordered` | https://ssgoi.dev/llms/transitions/scroll.txt |
