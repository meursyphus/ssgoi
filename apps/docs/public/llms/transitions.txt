# SSGOI mobile transition catalog

Choose the effect from the mobile interaction the user should understand. Each
linked spec contains its variants, supported props, required markup, and a
focused route-config example.

Main setup: https://ssgoi.dev/llms.txt

## Mobile UX patterns

| UX intent | transition | usual rule | spec |
| --- | --- | --- | --- |
| list → detail, hierarchical depth | `drill()` | `on` + `except` | https://ssgoi.dev/llms/transitions/drill.txt |
| compose, filters, temporary task | `sheet()` | `on` | https://ssgoi.dev/llms/transitions/sheet.txt |
| tabs or ordered horizontal steps | `slide()` | `ordered` | https://ssgoi.dev/llms/transitions/slide.txt |
| sibling pages with Material shared-axis motion | `axis()` | `ordered` | https://ssgoi.dev/llms/transitions/axis.txt |
| card or image expands into detail | `zoom()` | `from` / `to` | https://ssgoi.dev/llms/transitions/zoom.txt |
| vertical onboarding or editorial sequence | `scroll()` | `ordered` | https://ssgoi.dev/llms/transitions/scroll.txt |
