# SSGOI framework guides

Choose your rendering framework first. Each package supplies a common implementation;
router helpers are optional subpaths, not separate packages to install.
Next.js is the only router helper not marked experimental.

## Router helper imports

| Framework | Router | Import | Status |
| --- | --- | --- | --- |
| React | Next.js | `@ssgoi/react/nextjs` | Next.js App Router |
| React | Remix | `@ssgoi/react/remix` | Experimental |
| React | React Router | `@ssgoi/react/react-router` | Experimental |
| React | TanStack Router | `@ssgoi/react/tanstack-router` | Experimental |
| Svelte | SvelteKit | `@ssgoi/svelte/sveltekit` | Experimental |
| Vue | Vue Router | `@ssgoi/vue/vue-router` | Experimental |
| Vue | Nuxt | `@ssgoi/vue/nuxt` | Experimental |
| Solid | Solid Router | `@ssgoi/solid/solid-router` | Experimental |
| Solid | SolidStart | `@ssgoi/solid/solidstart` | Experimental |
| Qwik | Qwik City | `@ssgoi/qwik/qwik-city` | Experimental |
| Angular | Angular Router | `@ssgoi/angular/router` | Experimental |
| React Native | Expo Router | `@ssgoi/react-native/expo-router` | Experimental |

React, Vue, Solid, and Svelte helpers supply SsgoiRouteBoundary. Angular supplies
a structural directive with that name. Qwik City supplies useSsgoiRouteBoundary
so the page retains ownership of its DOM and projected slots. Expo supplies a
native file-based boundary; web presets and DOM attributes do not apply.

Router peers are optional and external to the library build. Their broad peer
ranges avoid constraining applications that do not use a helper. Check each
guide for the tested versions. Remix 2 follows its own React 18 requirements.
