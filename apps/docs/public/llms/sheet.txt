# SSGOI - sheet transition

Bottom sheet style. New page slides up from below. Use for **modal-like** flows (FAB → compose, "new item" screen, settings panel) that should feel temporary.

Setup guide: https://ssgoi.dev/llms.txt

## Behavior

- **`static`** (default): only the rising sheet moves. Background stays put — looks like the new page covers the old one cleanly.
- **`scale`**: background scales down slightly behind the rising sheet, giving a stacked, iOS-modal feel.
- **`blur`**: background blurs and recedes (a subtle scale + dim) behind the rising sheet — a modal pushing the page underneath out of focus.

The route rule resolves direction. Forward opens the sheet; backward closes it.

## Signature

```ts
import { sheet } from "@ssgoi/react/view-transitions";

sheet({
  type?: "static" | "scale" | "blur";  // default: "static"
  variant?: "default";                 // reserved — only "default" today
  options?: {};                        // reserved — no fields yet
}): TransitionConfig;
```

Returns one effect config with different forward/backward physics.

> Deprecated: `type: "background-scale"` — use `type: "scale"` instead.

## Usage

```ts
const config = {
  transitions: [
    { from: "/feed", to: "/compose", transition: sheet() },
    {
      from: "/",
      to: "/settings/:id",
      transition: sheet({ type: "scale" }),
    },
    {
      from: "/story",
      to: "/story/new",
      transition: sheet({ type: "blur" }),
    },
  ],
};
```
