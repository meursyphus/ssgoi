# SSGOI scroll transition

Use on full web pages for vertical chapters, showcases, paginated long-form
content, or another sequence where up and down communicate progress. Do not use
it as a mobile app-navigation preset.

Catalog: https://ssgoi.dev/llms/transitions.txt

## Props

```ts
import { scroll } from "@ssgoi/react/view-transitions";

scroll({
  type?: "directional" | "non-directional";  // default: "directional"
  variant?: "default";
  options?: object;
}): TransitionConfig;
```

- `directional`: route-rule direction controls the motion.
- `non-directional`: every transition moves upward.

## Example

```ts
const config = {
  transitions: [
    {
      ordered: ["/chapters/1", "/chapters/2", "/chapters/3"],
      transition: scroll(),
    },
  ],
};
```

This effect is separate from automatic browser scroll-position behavior:
https://ssgoi.dev/llms/scroll-restoration.txt
