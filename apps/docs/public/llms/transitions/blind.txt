# SSGOI blind transition

Use for a dramatic one-off reveal such as splash → app. Staggered slats sweep
across the viewport.

Catalog: https://ssgoi.dev/llms/transitions.txt

## Props

```ts
import { blind } from "@ssgoi/react/view-transitions";

blind({
  type?: "horizontal" | "vertical";  // default: "horizontal"
  variant?: "default";
  options?: object;
}): TransitionConfig;
```

## Example

```ts
const config = {
  transitions: [
    {
      from: "/intro",
      to: "/app",
      transition: blind({ type: "vertical" }),
    },
  ],
};
```
