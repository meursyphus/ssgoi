# SSGOI drill transition

Use for hierarchical mobile navigation such as list → detail or parent → child.
Forward drills in; backward drills out.

Catalog: https://ssgoi.dev/llms/transitions.txt

## Props

```ts
import { drill } from "@ssgoi/react/view-transitions";

drill({
  type?: "parallax" | "slide";  // default: "parallax"
  variant?: "default";
  options?: Record<string, never>;
}): TransitionConfig;
```

- `parallax`: the new page enters from the right while the old page moves
  slightly left underneath.
- `slide`: both pages translate a full viewport width—the new page enters from
  the right while the old page exits left—and opacity shifts between 0.5 and 1.


## Example

```ts
const config = {
  transitions: [
    {
      on: "/posts/**",
      except: "/posts",
      transition: drill(),
    },
  ],
};
```
