# SSGOI with TanStack Router

TanStack Router wiring only. Config syntax, transition catalog, options:
https://ssgoi.dev/llms.txt

```bash
npm install @ssgoi/react
```

## Setup

Everything wires in the root route — one `<Ssgoi>`, the shell classes, and
the boundary around `<Outlet />`:

```tsx
// app/routes/__root.tsx
import { createRootRoute, Outlet } from "@tanstack/react-router";
import { Ssgoi } from "@ssgoi/react";
import { config } from "~/components/ssgoi-config";
import { SsgoiRouteBoundary } from "~/components/ssgoi-route-boundary";

export const Route = createRootRoute({
  component: () => (
    <main className="relative z-0 min-h-dvh overflow-x-clip">
      <Ssgoi config={config}>
        <SsgoiRouteBoundary>
          <Outlet />
        </SsgoiRouteBoundary>
      </Ssgoi>
    </main>
  ),
});
```

Boundary — pathname (from router state) as both React key and transition id:

```tsx
// app/components/ssgoi-route-boundary.tsx
import { type ReactNode } from "react";
import { useRouterState } from "@tanstack/react-router";

export function SsgoiRouteBoundary({ children }: { children: ReactNode }) {
  const pathname = useRouterState({
    select: (state) => state.location.pathname,
  });

  return (
    <div key={pathname} data-ssgoi-transition={pathname}>
      {children}
    </div>
  );
}
```

Verify: navigate `/` → any page slides in from the right; back slides out.

## Beyond the basics

- Persistent shell (a tab header that stays while inner pages change): a
  section layout route owns its own boundary around its `<Outlet />` — keep
  the id as the real route, hold the key constant while routes share that
  shell. Key-scope reasoning: https://ssgoi.dev/llms/bottom-nav.txt
- Full example: https://github.com/meursyphus/ssgoi/tree/main/templates/tanstack-router
