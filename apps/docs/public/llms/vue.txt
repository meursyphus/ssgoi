# SSGOI with Nuxt

Use one config and one `<Ssgoi>` in the root layout.

```vue
<!-- components/demo-layout.vue -->
<script setup>
import { Ssgoi } from "@ssgoi/vue";
import { config } from "~/utils/ssgoi-config";
</script>

<template>
  <main class="relative z-0 min-h-dvh overflow-x-clip">
    <Ssgoi :config="config">
      <slot />
    </Ssgoi>
  </main>
</template>
```

## Page boundary

Put the transition id on the routed page root.

```vue
<template>
  <article :data-ssgoi-transition="route.path">
    <!-- page -->
  </article>
</template>
```

## Persistent layout

A parent page may own a boundary and render `<NuxtPage />`.

```vue
<!-- pages/products.vue -->
<template>
  <section :data-ssgoi-transition="route.path">
    <ProductTabs />
    <NuxtPage />
  </section>
</template>
```

Keep a boundary on each child page for tab-to-tab transitions. When the parent
and child leave together, SSGOI uses the outer changed boundary. When only the
child changes, it uses the child boundary.
