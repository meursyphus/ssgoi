# SSGOI with React Router

React Router (framework mode) wiring only. Config syntax, transition catalog,
options: https://ssgoi.dev/llms.txt

```bash
npm install @ssgoi/react
```

## Setup

Root — one `<Ssgoi>` + the shell classes:

```tsx
// app/root.tsx — the App component
import { Outlet } from "react-router";
import { Ssgoi } from "@ssgoi/react";
import { config } from "./components/ssgoi-config";

export default function App() {
  return (
    <main className="relative z-0 min-h-dvh overflow-x-clip">
      <Ssgoi config={config}>
        <Outlet />
      </Ssgoi>
    </main>
  );
}
```

Boundary — pathname as both React key and transition id, wired once with a
pathless layout route:

```tsx
// app/components/ssgoi-route-boundary.tsx
import { type ReactNode } from "react";
import { useLocation } from "react-router";

export function SsgoiRouteBoundary({ children }: { children: ReactNode }) {
  const { pathname } = useLocation();

  return (
    <div key={pathname} data-ssgoi-transition={pathname}>
      {children}
    </div>
  );
}

// app/routes/page-boundary.layout.tsx
export default function PageBoundaryLayout() {
  return (
    <SsgoiRouteBoundary>
      <Outlet />
    </SsgoiRouteBoundary>
  );
}

// app/routes.ts — wrap your pages with it
layout("routes/page-boundary.layout.tsx", [
  index("routes/home.tsx"),
  route("posts/:postId", "routes/posts.$postId.tsx"),
]),
```

Verify: navigate `/` → any page slides in from the right; back slides out.

## Beyond the basics

- Persistent shell (a tab header that stays while inner pages change): keep
  the boundary id as the real route, but hold the React key constant while
  routes share that shell — add a `name` prop and branch the key on it.
  Key-scope reasoning: https://ssgoi.dev/llms/bottom-nav.txt
- Full example: https://github.com/meursyphus/ssgoi/tree/main/templates/react-router
