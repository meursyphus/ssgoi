# SSGOI - drill transition

iOS-style hierarchical navigation. Use when going from a list to a detail screen, or any parent → child navigation where the user feels they're drilling deeper into content.

Setup guide: https://ssgoi.dev/llms.txt

## Behavior

- **`parallax`** (default): new page slides in from the right; old page eases slightly left under it, hinting it's still there.
- **`slide`**: new page slides in from the right while the old page cross-fades underneath. Flatter and less directional than `parallax`.

`enter` is forward navigation (e.g. list → detail). `exit` is the reverse — old page comes back from the left.

## Signature

```ts
import { drill } from "@ssgoi/react/view-transitions";

drill({
  enter: string;                       // destination path (forward)
  exit: string;                        // source path (forward)
  type?: "parallax" | "slide";         // default: "parallax"
  variant?: "default";                 // reserved — only "default" today
  options?: {};                        // reserved — no fields yet
}): SsgoiPathTransition[];
```

Returns a directional pair: one entry for forward (`exit → enter`) and one for backward (`enter → exit`).

> Deprecated: `type: "crossfade"` — use `type: "slide"` instead.

## Usage

```ts
const config = {
  transitions: [
    drill({ enter: "/post/*", exit: "*" }),
    drill({ enter: "/settings/*", exit: "/settings", type: "slide" }),
  ],
};
```

Drop the result directly into `transitions` — arrays are flattened automatically.
